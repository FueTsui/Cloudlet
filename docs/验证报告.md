# Cloudlet 2.0 验证报告

验证环境：Windows 11 x64，.NET SDK 10.0.401，Windows App SDK 2.5.1，捆绑 rclone 1.70.3，本机已有 WinFsp。应用采用自包含发布，不依赖另装 .NET。

## Cloudlet 品牌与图标

2.0 将应用名称、EXE、程序集产品信息、窗口、侧栏、关于、托盘、导出文件默认名和安装包统一为 Cloudlet。内部 C# 命名空间、原 AppData/cache 位置和原 v2 单实例标识保留兼容用途；旧 Python 实现已清理；图标原图与用户配置保留。

黑白 PNG 来自 `output/imagegen/cloud-soft-3d-v2`，源文件未改动；复制的 PNG 与来源 SHA256 一致。两套 ICO 含 16、20、24、32、40、48、64、128、256 像素共九帧，每帧通过 Windows 解码验证，完整记录见 `assets/Cloudlet/icon-manifest.json`。默认 EXE 和安装器使用黑云，应用窗口按浅色/深色切换黑云/白云；任务栏及托盘按系统任务栏主题选择。

应用内检查读取实际窗口小/大 HICON，并核验托盘图标已载入、标题与两种主题选择正确；启动命令身份检查只读执行，不修改实际启动项。`scripts/verify-branding.ps1` 从 EXE 和安装器的 PE 资源读取图标，逐帧与源 ICO 比较，报告和提取预览位于 `artifacts/verification/2.0.0`。未执行安装器或切换 Windows 全局主题。

## 核心验证

最终真实集成测试 **16 项通过、0 失败**。报告保存在源码目录 `artifacts/verification/2.0.0/core-tests.json`。

1. 实际执行捆绑 rclone 并读取版本。
2. 本地 `lsjson`、`size` 与连接检查，包括空格和中文路径。
3. copy 预演不修改目标，真实复制的过滤与 SHA256 内容一致。
4. sync 预演保留目标额外文件，实际同步仅清理隔离测试文件。
5. check 对一致和不同内容返回正确退出码。
6. 取消传输并等待自己的子进程退出。
7. WebDAV 配置的密码遮蔽、重名保护、备份和删除。
8. 本机 WebDAV：未授权返回 401，配置后认证成功、浏览并下载中文文件，哈希一致。
9. 真实提供商目录、SFTP 密码遮蔽、S3/local 配置；保存前实际配置不变，保存后仅加入目标段；local 实际浏览文件。
10. 提供商向导取消、重名、外部配置修改及提交期间取消均保持原配置。
11. OAuth 后续问题和取消流程，没有授权真实账户。
12. OAuth 本机授权链接、持续等待超过原 4 秒超时、取消后回收独立进程且保持原配置；此测试禁止打开浏览器。
13. 旧版完整挂载参数、设置迁移、导入导出和原子保存。
14. 非法参数、相同路径和嵌套传输拒绝。
15. WinFsp 创建真实空闲盘符，读取哈希一致；保持脏写句柄时拒绝停止；关闭句柄后缓存写回，再次读写成功；卸载后盘符消失。
16. 本轮测试没有遗留 rclone 子进程。

测试全部使用隔离临时目录和本机服务，没有读取用户云端文件或修改生产数据。停止挂载会检查本次私有控制接口的上传队列和本次缓存的脏写元数据；不能确认写回完成时保留挂载并提示重试。

## 界面验证

Release 编译成功，0 警告、0 错误。应用的 `--ui-smoke` 模式使用独立设置和独立 rclone 配置，以真实 WinUI 控件渲染七个页面的 Light/Dark 两种主题，以及七个 1000×720 物理像素窄窗口场景，并检查卡片背景主题对比。页面较长时另存滚动到底部的截图。

原生主题切换的卡片残留浅色问题已通过 ThemeResource 修复；内容横向伸展、导航折叠和 DPI 初始窗口尺寸已检查。渲染测试在主题切换前主动触发 GC，防止因托管包装对象生命周期造成漏更新。

提供商页面另覆盖 SFTP、S3、Google Drive、OneDrive 的双主题表单和 OneDrive 授权确认页，共 10 个场景。应用内调用实际页面流程，检查搜索、必填名称、密码输入控件、S3 条件字段、暂存、保存并刷新、重名保护、上一步保留表单和取消不改配置。发布版本证据位于 `artifacts/verification/2.0.0/published-ui`。

本轮测试发现并修复了重复进入提供商页面时控件父节点未释放的问题。退出清理异常现在使用独立提示，只有挂载停止失败才显示“尚未安全卸载”；对话框跟随当前应用主题。

这些是应用内渲染与程序调用验证，不代表桌面鼠标、键盘、托盘菜单或系统文件选择器的人机操作验收。当前工具未开放原生桌面控制 API，所以此类交互没有执行。

## 打包与边界

交付包含 Windows 11 x64 自包含应用目录、ZIP 和 Inno Setup 安装器。发布脚本记录每个文件的字节数与 SHA256，打包前逐项复核，生成内容清单和安装包/ZIP 校验值。WinFsp 原始 MSI 的 Authenticode 签名在本机检查为 Valid。Cloudlet 应用及安装包没有配置发行者签名证书。

安装器默认每用户安装、不自动创建登录启动项，WinFsp 驱动安装为默认未选的可选操作。升级前检查运行中的应用。卸载只清理严格匹配本安装目录的 Cloudlet 登录启动项，不删除用户配置、缓存或原版程序。

未执行：安装、升级、卸载、重启后登录启动、真实用户云账号及其完整 OAuth 授权、外网大文件压力测试、驱动缺失环境，以及 Windows 11 其他构建版本/缩放比例。页面没有提供双向同步或计划任务；通用配置向导暂不支持加密配置文件合并，也不修改已有同名连接。

旧 Python 源码和构建链已移除，GitHub 历史提交与 v1.0.0 发布仍可查阅。当前代码在 `src`，构建和打包入口在 `scripts`。
