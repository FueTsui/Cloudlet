# Cloudlet 2.0.0 功能对照与重构说明

本次重构面向 Windows 11 x64，使用 C#、.NET 10、WinUI 3 和 Windows App SDK 2.5.1。旧 Python/PySide6 源码、PyInstaller 构建脚本及旧构建目录已移除。新程序通过独立的 rclone 子进程执行存储操作，发布包保留现有 rclone v1.70.3。

本文记录已落地功能及其验证边界。测试使用隔离的本地文件和本机 WebDAV 服务；真实云端账号与桌面交互的未测项目单独列出。

## 提供商设置页面

左下角仅保留版本号，移除了“基于 rclone · Windows 原生体验”描述。“添加其他存储”在应用内打开原生页面，不再启动交互式命令行。页面从当前引擎读取提供商目录和参数，支持搜索、基础/高级选项、枚举选择、开关、密码框及提供商相关的条件字段；后续账号选择等问题继续显示在页面中。需要 OAuth 的服务通过用户点击后打开系统浏览器完成授权。

向导使用自己的暂存配置和后台进程，完成后显示保存操作；取消或退出会清理暂存状态。保存时只添加新连接，保留已有配置的原始内容，并建立备份；遇到重名、外部修改或加密配置时停止保存。暂不支持在此向导中修改已有连接；已有连接的浏览、检测、挂载和删除保持原有入口。

目录支持的提供商数量不代表所有云端服务已经连接验证。当前捆绑引擎返回 64 种提供商；基础配置与后续步骤遵循该引擎的实际协议，专业选项保留官方名称及部分英文帮助。真实云账号的 OAuth 往返与第三方服务连通性列入未测边界。

## Cloudlet 名称与图标

应用名称变更为 Cloudlet，主程序为 `Cloudlet.exe`，核心程序集为 `Cloudlet.Core.dll`；窗口、托盘、关于和安装器统一显示新名称。黑白云图标来自用户提供的素材目录，浅色窗口采用黑云、深色窗口采用白云，任务栏和托盘按系统任务栏主题独立选择。EXE、快捷方式和安装器采用黑云作为固定图标。

原 C# 项目路径和命名空间保留内部兼容用途。设置继续保存在原 `RcloneLink\v2` 路径，缓存、配置写入锁和 v2 单实例管道不重命名，避免与旧版同时写入。用户保存设置时才更新 Cloudlet 登录启动项，并仅迁移通过完整命令和产品文件信息核验的旧启动项；不在构建或打包时修改实际用户注册表。已有自定义引擎及配置路径保留。

## 数据与迁移

- 新应用状态保存在 `%APPDATA%\RcloneLink\v2\state.json`。
- 首次启动且新状态不存在时，程序只读迁移旧 `%APPDATA%\RcloneLink\settings.json` 中的 rclone 路径、主题、托盘显示和默认参数，并导入其 `last_mount_list` 指向的旧挂载列表；迁移结果保存到新的 `v2\state.json`。此后读取新状态。旧设置、旧挂载 JSON 和原 `rclone.conf` 均保留，不在启动迁移时覆盖。
- 旧程序目录另一个 `settings.json` 不会被自动扫描；旧平铺挂载 JSON 仍可在界面显式导入。自动迁移不等于自动开始挂载，新版本自动挂载默认关闭。
- 新状态由 `Settings` 和 `Mounts` 组成；应用设置包括 rclone/config 路径、主题、托盘、关窗行为、登录启动、自动挂载和默认参数。
- 每个挂载具有 `Id`、`Name`、`Remote`、`MountPoint`、`Options`、`AutoMount`。旧 snake_case 参数可由导入器转换，行级覆盖值应保留。
- 新建 WebDAV 应默认验证 TLS；密码不写入日志或命令行。rclone obscure 是可逆的凭据遮蔽，并非独立安全存储。
- 旧启动项名为 `RClone GUI`。安装器不改动旧启动项，也不自动启动新程序的登录启动；如存在旧自启动，用户应在旧版或 Windows 启动应用中停用。

## 挂载与传输边界

挂载停止应针对应用自己启动的进程，并等待其结束；不得重启 Explorer 或批量终止其它 rclone 实例。盘符已经存在时不应判定为本应用挂载成功。关窗隐藏与退出是不同操作，退出需要等待清理。

`copy` 复制源目录内容，不删除目标额外文件；`sync` 会让目标与源保持一致，可能删除目标额外文件。预演使用 `--dry-run`，不执行实际修改；真实同步需要界面明确确认。`check` 检查文件差异，不传输内容。不同远程支持的时间戳、哈希、权限和容量能力可能不同。

当前发布包沿用 rclone v1.70.3，而官方在线文档可能比该版本新。新增参数必须对照捆绑二进制的 `--help` 验证，不能仅凭在线文档承诺支持。

## 构建与打包

脚本通过 `-DotnetPath`、`DOTNET_ROOT` 或 `PATH` 选择 .NET SDK，不安装或修改系统 SDK。首次从源码构建前运行 `scripts/fetch-dependencies.ps1`，下载并校验固定版本的 rclone 与 WinFsp 安装器。

```powershell
pwsh -File .\scripts\build.ps1
pwsh -File .\scripts\package.ps1 -SkipBuild
```

发布目录为 `release\Cloudlet-2.0.0-win-x64`，包含 .NET 与 Windows App SDK 的自包含运行文件、rclone、WinFsp MSI、图标和文档。保留所有发布依赖文件，不能只取 EXE。再次构建先生成独立临时目录，成功后将旧同版本输出移动到 `release\.history`。

打包产生 ZIP、Inno Setup 安装器、逐文件内容清单以及 SHA256 校验文件；用户 AppData 不被构建脚本修改。内容清单记录相对路径、字节数、SHA256，打包前逐项校验。构建时间和工具版本记录在 `build-info.json`；提供可核对的内容清单，不承诺不同机器之间构建产物逐字节一致。

安装器要求 Windows 11（Build 22000 及以上），新安装默认位于当前用户 `%LOCALAPPDATA%\Programs\Cloudlet`，无需应用级管理员权限。沿用原 AppId，设置 `UsePreviousAppDir=yes`、`UsePreviousPrivileges=no` 和 `PrivilegesRequired=lowest`：已有同用户、同注册表视图的安装沿用其目录，使改名后的卸载登记与原卸载日志保持一致；不继承或卸载 HKLM 机器级安装。运行中的 Cloudlet 或 RcloneLink 会阻止安装，安装器不自动终止挂载或传输。WinFsp 仅在用户勾选时启动官方 MSI 并独立请求管理员权限。卸载不删除用户配置或缓存；仅当当前用户 `Run\Cloudlet` 与本安装目录的 `"Cloudlet.exe" --minimized` 完全相符时才清理该启动项，保留其他值。
